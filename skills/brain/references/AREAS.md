# Areas

An **area** is one slice of a repository's tracked source, walked by one sub-agent. Split `git -C <root> ls-files` into areas: one per context the repository's pairings name, else one per app in `docs/STRUCTURE.md`, else one per top-level source folder. A pairing line names a context after the repository's slug: `node <this file's folder>/../scripts/recall.mjs <brain> --repo <slug> --type term` lists them, drafts included, and RECALL.md's script bullets say how to read a line. Give a context the folder or package that carries its name. When none does, leave the context out, and let the next rule split its files. With no brain open, or with no pairing that names a context, split by the code alone. Source the contexts or apps leave out takes one area per package, such as each of a monorepo's `packages/*`, else per top-level folder holding it. A sub-agent's cost grows faster than its area, since every turn rereads all it has read so far, yet each one pays for its brief. Count an area's source files, tests not counted: split an area holding more than about 60 by its next folder level, the files left directly in its folder forming one more area. Then join each folder or package area holding fewer than about 10 to its smallest sibling under the same parent folder, while the two stay within about 60, and name it by both folders, as `a+b`. A context or an app stays its own area however small. Tests belong to the area they test; generated and vendored code belongs to none, and so does an embedded brain's `.brain/` folder, by FORMAT.md's **Embedded brain**. The split is done when every tracked source file outside generated and vendored code and the brain belongs to exactly one area.

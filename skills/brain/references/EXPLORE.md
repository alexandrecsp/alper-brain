# Explore

The `explore` branch of [`brain`](../SKILL.md): read a registered repository's code and write what it does into the active brain as **explored notes**, for an *outsider*: someone who never opens the code, such as a product owner or a teammate on their first day. An outsider clones only the brain, so these notes are all they have of the repository. [FORMAT.md](FORMAT.md) defines registered, linked, explored notes, the `feature` type, current and behind, and the snapshot.

Explore writes, restamps, moves and deletes explored notes and the overview in the card's body, and nothing else. An authored note it finds wrong, and a contract no note records, go to **Record** in [SKILL.md](../SKILL.md) as drafts.

Steps 1 to 3 run for every picked repository together: every snapshot taken, every repository surveyed, and every area's scribe dispatched, in waves. Steps 4 to 6 then run one repository at a time, each committed before the next is merged.

1. **Pick the repositories.** With an argument, the repository it names, by slug or by a path inside its clone; when it is not registered, tell the user to run `/brain setup` and stop. With none, every registered repository whose explored notes are missing or behind. A repository that is not linked cannot be read: leave it out, and list it at the end with the hint `/brain link`. For each picked one, take a snapshot by FORMAT.md; its **target** is `git -C <snapshot> rev-parse HEAD`, and its **previous** commit is the card's `explored` line, or none. Every read from here on is from the snapshot, so the notes describe the default branch, never the clone's current branch or its uncommitted work. Done when each picked repository has its snapshot, its target and its previous commit or none.

2. **Survey.** Read the snapshot's README, manifests (`package.json`, `pyproject.toml`, `go.mod`, …), `docs/STRUCTURE.md`, the [domain docs](../../model-domain/references/DOMAIN-DOCS.md) with every glossary and ADR, the card, and every note in `repos/<slug>/` and in its `explored/` folder (a note is explored when its frontmatter has an `explored` line, authored otherwise), and every `shared/` note whose `repos` names the slug. Split the snapshot's tracked source into **areas** by [AREAS.md](AREAS.md). With a previous commit that is an ancestor of the target, `git -C <snapshot> diff --name-only <previous> <target>` lists the changed files: scout only the areas holding one, and keep each explored note whose **Sources** list none of them. Otherwise scout every area. Done when the split is done, and each area is marked to scout or kept.

3. **Fan out.** Dispatch one `alper-brain:scribe` agent per area to scout, across every picked repository, in waves by BRIEF.md's **Fanning out**. Open each brief with the Context block by [BRIEF.md](BRIEF.md): **Works in** the snapshot, read only; **Docs** its glossary and the absolute paths of FORMAT.md and PROSE.md; **Notes** the explored notes whose **Sources** fall in its area, plus the path and description of every authored note in `repos/<slug>/` (one with no `explored` line) and every `shared/` note whose `repos` names the slug; **Writes** the scratch folder `<brain>/.sdd/explore/<slug>/<area>/`. Then give each its area's paths, the area list, the registered slugs with their one-line summaries, each ADR's title and decision, the target, and this brief:

   > Walk this area for an outsider who will never read its code: a product owner, or a teammate on their first day. Write its explored notes by FORMAT.md and PROSE.md into the scratch folder (you have no Bash: the parent runs PROSE.md's **Check**, so count your sentences against its rule 3 yourself): one `feature` note per thing a user, an operator or another system can do through this area (who does it, what happens, and its **rules**: limits, validations, defaults, permissions, states and the moves between them, money and time calculations); one `concept` note per process that runs in several steps, such as a signup, a payment or a nightly job, and per entity a reader needs on its own. Stamp each with the target, write the body in the domain's words, and list its files only in **Sources**. A feature belongs to the area holding its entry point, and a flow that crosses areas to the area where it starts: link the rest by `[[name]]`, from the area list. For each explored note given to you, write its updated version, or mark it kept or deleted. Report:
   >
   > - **Notes**: each note's path, description and mark (new, kept, updated or deleted).
   > - **Integrations**: each other repository and external system it talks to, what passes between them, and which way, each with its `path:line` in the snapshot.
   > - **Contradicted**: each authored note given to you that the code contradicts, with what the code does instead and its `path:line`. Open an authored note only when its description bears on this area.
   >
   > Report every field, writing "none" for an empty one.

   Done when every scouted area's report has every field and every note it lists as new or updated exists in its scratch folder, re-dispatching a scribe whose report fails either.

4. **Merge.** Write the card's new overview, held for step 6, from the reports' descriptions: what the repository does and for whom, then each feature note as a `[[link]]`. Rename scratch notes whose names clash across areas, or with a note of the brain they do not replace, and point every `[[link]]` to them at the new name. Mark each kept area's explored notes kept (restamped). Hold back for step 6 each integration with a registered repository that no `contract` note or draft records (one seen from both sides is one candidate contract) each contradicted authored note, and each authored note or `topic` linking an explored note marked deleted or renamed. Check the scratch folders by [PROSE.md](PROSE.md)'s **Check**, and rewrite each flagged sentence in its scratch note. Done when no two scratch notes share a name, none shares a name with a note it does not replace, every `[[link]]` in a scratch note and in the overview names a scratch note or a note of the brain, every explored note of the repository is marked new, kept, updated or deleted, and the check prints `prose: ok`.

5. **Propose.** Show the user the repository's new, updated and deleted notes, each with its path and description, and the overview's new text. Read a scratch note's full text only when the user asks for it. The user picks: all of them by default. Done when the user has picked.

6. **Commit.** Move into `repos/<slug>/explored/` each explored note still outside it, by [MIGRATE.md](MIGRATE.md)'s **Explored notes**, then move the picked scratch notes into it, restamp the kept notes, delete the notes marked deleted, and write the overview into the card's body unless the user dropped it. Check the card by [PROSE.md](PROSE.md)'s **Check**, and rewrite each flagged sentence before the commit. Write the card's `explored` line when the user picked every change; when they dropped one, keep the card's line as it was, so the next run scouts those areas again. Commit all of it together as `Explores <slug> at <short target>`, staging each path. Then write each held-back contract as a `contract` draft in `shared/`, naming its producer and consumers, and each authored-note fix, and each link to a deleted or renamed explored note, as an `update` or `delete` draft, by **Record** in [SKILL.md](../SKILL.md). Done when the card's check prints `prose: ok`, `git -C <brain> status --porcelain -- repos/<slug>/` lists nothing, and each held-back candidate sits in a draft.

7. **Clean up and hand over.** Remove each snapshot by FORMAT.md, and delete `<brain>/.sdd/explore/`. Report, per repository: its target, and how many notes are new, kept, updated and deleted. List the unlinked repositories left out, with the hint `/brain link`. Say that nothing was pushed, and that `/brain sync` shares the notes with the team, consolidating the drafts this run wrote: name each, or say there are none. Done when no snapshot is left in `git -C <root> worktree list`, and the user has the report.

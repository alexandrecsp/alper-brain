# Export

The `export` branch of [`brain`](../SKILL.md): move an embedded brain, by [FORMAT.md](FORMAT.md)'s **Embedded brain**, out of its host into a repository of its own, its history included, so it can cover more repositories. Afterwards the host is a registered repository like any other, linked from the new brain.

1. **Check the host.** When the active brain is not embedded, say so and stop. The host must be clean (`git -C <host> status --porcelain` lists nothing), on its default branch (`origin/HEAD`'s, or the one the user names for a `local only` host), and hold no other branch with brain commits its default branch lacks (`git -C <host> log --oneline --branches --not HEAD -- brain/` lists nothing), since only the checked-out branch's history moves. When `.brain/locks/` holds a claim, ask whether that build still runs. List each check that fails, with its fix (commit, switch, merge the branch, or wait for the build), and stop. Done when every check holds.

2. **Pick the place.** Ask where the new brain goes, recommending `~/brains/<host slug>`, and for its remote URL, or none for now. The path must not exist yet, or be an empty folder. Done when you hold the path, and the URL or none.

3. **Split the history.** `git -C <host> subtree split --prefix=brain -b brain-export` writes a branch holding only `brain/`'s commits, its files at the root; when `git subtree` is missing, say so and stop. Then `git clone --quiet --branch brain-export <host> <path>`, `git -C <path> branch -m main`, `git -C <path> remote remove origin`, and `git -C <host> branch -D brain-export`. Done when `<path>/BRAIN.md` exists and `git -C <path> log --oneline` lists the brain's commits.

4. **Move the local work.** Remove each snapshot first, since the host registers it as a worktree: each path `git -C <host> worktree list` prints under `<host>/brain/.brain/snapshots/`, by `git -C <host> worktree remove --force <path>`. Then move every entry of `<host>/brain/.brain/` into `<path>/.brain/`, and delete the emptied folder. `.brain/links.json` keeps the host's entry: the clone has not moved. Done when `<host>/brain/.brain/` is gone and `<path>/.brain/links.json` names the host.

5. **Make it a brain of its own.** In the new brain, write `CLAUDE.md` from [SETUP.md](SETUP.md)'s **CLAUDE.md**, and replace `BRAIN.md`'s paragraph from SETUP.md's **Joining an embedded brain** with the template's two paragraphs on joining. Run `node <this skill's folder>/scripts/timeline.mjs <path>`, since the split gave every commit a new SHA. Commit all three as `Moves the brain out of <host slug>`, with no key, by the `commit` skill. Given a URL, run `git -C <path> remote add origin <url>`. Done when `git -C <path> rev-parse --show-toplevel` prints the path and `git -C <path> status --porcelain` lists nothing.

6. **Remove it from the host.** Run `git -C <host> rm -r --quiet brain`, and delete the **Brain** line SETUP.md's step 9 wrote into the host's agent file, keeping its other references. Commit both in the host as `Moves the brain to its own repository`, with the key the `commit` skill's **Find the key** gives. Done when `<host>/brain/` is gone and `git -C <host> status --porcelain` lists nothing.

7. **Hand over.** Report the new brain's path and name, how many commits it holds, and the host's commit. Say that nothing was pushed: the host's commit ships like any change, and the first `/brain sync` pushes the brain once it has a remote. From now on, the user launches Claude in the new brain, with `--add-dir <host>` to open the host. Each teammate clones the new brain and runs `/brain setup` there; after pulling the host's commit, they move the `brain/.brain/` git leaves in their clone of the host, their own specs and drafts, into the new brain's `.brain/`. On the brain page, they add the new folder with **Add brain**. Done when the user has the report.

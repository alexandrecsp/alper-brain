# Export

The `export` branch of [`brain`](../SKILL.md): move an embedded brain, by [FORMAT.md](FORMAT.md)'s **Embedded brain**, or a local one, by its **Local brain**, out of its host into a repository of its own, its history included, so it can cover more repositories. Afterwards the host is a registered repository like any other, linked from the new brain.

1. **Check the host.** When the active brain is local, follow **Local brain** below instead. When it is neither embedded nor local, say so and stop. The host must be clean (`git -C <host> status --porcelain` lists nothing), on its default branch (`origin/HEAD`'s, or the one the user names for a `local only` host), and hold no other branch with brain commits its default branch lacks (`git -C <host> log --oneline --branches --not HEAD -- .brain/` lists nothing), since only the checked-out branch's history moves. When `<host>/.brain/.local/locks/` holds a claim, ask whether that build still runs. List each check that fails, with its fix (commit, switch, merge the branch, or wait for the build), and stop. Done when every check holds.

2. **Pick the place.** Ask where the new brain goes, recommending `~/brains/<host slug>`, and for its remote URL, or none for now. The path must not exist yet, or be an empty folder. Done when you hold the path, and the URL or none.

3. **Split the history.** `git -C <host> subtree split --prefix=.brain -b brain-export` writes a branch holding only `.brain/`'s commits, its files at the root; when `git subtree` is missing, say so and stop. Then `git clone --quiet --branch brain-export <host> <path>`, `git -C <path> branch -m main`, `git -C <path> remote remove origin`, and `git -C <host> branch -D brain-export`. Done when `<path>/BRAIN.md` exists and `git -C <path> log --oneline` lists the brain's commits.

4. **Make it a brain of its own.** The split put the brain's files at `<path>`'s root: create `<path>/.brain/`, and `git -C <path> mv` every top-level entry other than `.brain/` into it, `.gitignore` included, so each file keeps its history. Write `<path>/CLAUDE.md` from [SETUP.md](SETUP.md)'s **CLAUDE.md**, set `kind: standalone` in `.brain/BRAIN.md`, and replace its paragraph from SETUP.md's **Joining an embedded brain** with the template's two paragraphs on joining. Commit all of it as `Moves the brain out of <host slug>`, with no key, by the `commit` skill. Given a URL, run `git -C <path> remote add origin <url>`. Done when `git -C <path> rev-parse --show-toplevel` prints the path, `.brain/BRAIN.md` holds `kind: standalone`, and `git -C <path> status --porcelain` lists nothing.

5. **Move the local work.** Remove each snapshot first, since the host registers it as a worktree: each path `git -C <host> worktree list` prints under `<host>/.brain/.local/snapshots/`, by `git -C <host> worktree remove --force <path>`. Then move each file and folder of `<host>/.brain/` that git ignores (`git -C <host> ls-files --others --ignored --exclude-standard --directory -- .brain` lists them) to the same path under `<path>/.brain/`, which its `.gitignore` already ignores, creating the folders. `.local/repos.json` keeps the host's entry: the clone has not moved. Done when `git -C <host> ls-files --others --ignored --exclude-standard -- .brain` lists nothing and `<path>/.brain/.local/repos.json` names the host.

6. **Remove it from the host.** Run `git -C <host> rm -r --quiet .brain`, delete the emptied `<host>/.brain/` folder, and delete the **Brain** line SETUP.md's step 9 wrote into the host's agent file, keeping its other references. Commit both in the host as `Moves the brain to its own repository`, with the key the `commit` skill's **Find the key** gives. Done when `<host>/.brain/` is gone and `git -C <host> status --porcelain` lists nothing.

7. **Hand over.** Report the new brain's path and name, how many commits it holds, and the host's commit. Say that nothing was pushed: the host's commit ships like any change, and the first `/brain sync` pushes the brain once it has a remote. From now on, the user launches Claude in the new brain, with `--add-dir <host>` to open the host. Each teammate clones the new brain and runs `/brain setup` there; after pulling the host's commit, they move what git leaves in `.brain/` of their clone of the host, their own specs and drafts, to the same paths under the new brain's `.brain/`. On the brain page, they add the new folder with **Add brain**. Done when the user has the report.

## Local brain

A local brain is a repository of its own already, so its history moves with its `.git` folder.

1. **Check the brain.** `git -C <brain> status --porcelain` lists nothing; commit or discard what it lists first. When `<brain>/.local/locks/` holds a claim, ask whether that build still runs. List each check that fails, with its fix, and stop. Done when every check holds.

2. **Pick the place**, by step 2 above. Done when you hold the path, and the URL or none.

3. **Move the folder.** Remove each snapshot first, since the host registers it as a worktree: each path `git -C <host> worktree list` prints under `<brain>/.local/snapshots/`, by `git -C <host> worktree remove --force <path>`. Then move `<host>/.brain/` to `<path>/.brain/`, move its `.git` folder up to `<path>/.git`, and delete the `.brain/` line from the host's exclude file, the path `git -C <host> rev-parse --git-path info/exclude` prints. `.local/repos.json` keeps the host's entry: the clone has not moved. Done when `<path>/.brain/BRAIN.md` and `<path>/.git` exist, `<host>/.brain/` is gone, and the exclude file no longer names it.

4. **Make it a brain of its own.** In the new brain, write `<path>/CLAUDE.md` from [SETUP.md](SETUP.md)'s **CLAUDE.md**, set `kind: standalone` in `.brain/BRAIN.md`, and replace its paragraph from SETUP.md's **A local brain** with the template's two paragraphs on joining. Stage everything with `git -C <path> add -A`, so git records each file as moved into `.brain/`, and commit as `Moves the brain out of <host slug>`, with no key, by the `commit` skill. Given a URL, run `git -C <path> remote add origin <url>`. Done when `git -C <path> status --porcelain` lists nothing.

5. **Hand over.** Report the new brain's path and name, and that nothing in the host changed. Say that nothing was pushed: the first `/brain sync` pushes the brain once it has a remote. From now on, the user launches Claude in the new brain, with `--add-dir <host>` to open the host. Each teammate clones the new brain and runs `/brain setup` there. On the brain page, the user removes the old card and adds the new folder with **Add brain**. Done when the user has the report.
